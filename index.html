🎨 Script Principal: generar_visualizacion_3d_scopus.py

Este es el script más importante del proyecto. Se encarga de transformar los datos limpios y enriquecidos en una visualización 3D interactiva completamente funcional en HTML/JavaScript/Canvas.

📍 Ubicación: Raíz del repositorio
📄 Entrada: dataset_limpio_enriquecido.csv
📊 Salida: visualizacion_clouster_3d.html (archivo interactivo de 1.4 MB)

⚙️ Funcionalidades Principales del Script

📍 Generación de Nodos 3D

• Distribución espacial de artículos en 5 clusters temáticos
• Posicionamiento radial y helicoidal para evitar superposiciones
• Tamaño dinámico según número de citas
• Colores específicos por cluster

🔗 Construcción de Aristas (Edges)

• Conexiones por cluster (líneas tenues)
• Conexiones por autor compartido (líneas fuertes)
• Conexiones por palabra clave (líneas medias)
• Sistema de ponderación inteligente

🏷️ Clasificación Temática

Detecta automáticamente a qué cluster pertenece cada artículo analizando términos clave:
• Social: Communication, interaction, social media
• Académico: Learning, teaching, classroom, pedagogy
• Creativo: Design, creativity, content creation
• Mixto: Combina múltiples ejes

📊 Análisis Bibliométrico

• Cálculo de autores destacados por cluster
• Extracción de términos importantes
• Presencia de términos en clusters
• Estadísticas de citas y productividad

🔄 Flujo de Procesamiento de Datos

1
Carga del Dataset Lee el archivo CSV limpio con ~3000 artículos y sus atributos enriquecidos
↓
2
Análisis de Clustering Detecta términos clave en cada artículo y lo asigna a uno de los 5 clusters
↓
3
Generación de Nodos Crea nodos 3D posicionados espacialmente según cluster y características del artículo
↓
4
Construcción de Aristas Establece conexiones (edges) entre nodos basadas en relaciones de autores y palabras clave
↓
5
Generación de HTML Dinámico Crea un archivo HTML completo con JavaScript embebido para renderizar la visualización
↓
6
Archivo Interactivo Se genera visualizacion_clouster_3d.html listo para abrir en navegador

🔧 Funciones Clave del Script

build_nodes(df)

Función principal que crea todos los nodos del mapa 3D.

Parámetros: - df: DataFrame con artículos limpios Retorna: - nodes: Lista de diccionarios con propiedades 3D - cluster_stats: Estadísticas por cluster Propiedades de cada nodo: - id, x, y, z: Posición en 3D - cluster: Categoría temática - color: Color hexadecimal (#4ea8de, #7b6dff, etc.) - size: Tamaño basado en citas - title, authors, keywords, doi: Información del artículo - cluster_reason: Explicación de clasificación - highlight_terms: Palabras más importantes

build_edges(nodes)

Crea las conexiones entre nodos para visualizar relaciones.

Tipos de relaciones: - "cluster:NOMBRE" → Peso 0.2-0.3 (línea tenue) - "keyword" → Peso 0.65 (línea media) - "autor" → Peso 0.95 (línea fuerte) Algoritmo: 1. Agrupa nodos por cluster, autor y palabra clave 2. Conecta nodos dentro de cada grupo 3. Asigna pesos según tipo de relación

terminos_detectados(texto, terminos)

Detecta automáticamente términos de diccionarios temáticos en el texto.

Diccionarios de términos: CLUSTER_TERMS: { "social": ["communication", "interaction", "social media", ...], "academico": ["learning", "teaching", "classroom", ...], "creativo": ["design", "creativity", "content creation", ...] } Retorna los términos encontrados como lista

build_html(nodes, cluster_stats, edges)

Genera el HTML/JavaScript completo con la visualización interactiva.

Incluye: - Canvas de 1920x1080 mínimo - Motor de renderización 2D con rotación 3D - Interactividad: zoom, rotación, búsqueda - Panel lateral con información del artículo - Filtros por año, cluster, búsqueda de texto
