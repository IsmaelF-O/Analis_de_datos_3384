📊 Análisis de Datos Bibliométricos 3D

Este proyecto realiza una limpieza y análisis profundo de datos bibliométricos utilizando Python. Se implementan técnicas de clustering para visualizar relaciones entre artículos académicos en un espacio 3D interactivo.

Características:

  • Limpieza de datos con Pandas
  • Identificación de duplicados con ORCID
  • Visualización 3D interactiva de clusters
  • Análisis de conexiones entre artículos

Tecnologías utilizadas:

Backend: Python (Pandas, NumPy, Scikit-learn)

Frontend: HTML5, JavaScript (Three.js para 3D)
